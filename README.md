# YUNSEUL VR — 송도 시티

공개 **OpenStreetMap** 건물·도로·공원·수면 데이터로 인천 송도국제도시를 3D로 재구성하고, 걷기 / 자전거 / 자동차로 이동할 수 있는 WebXR VR 환경입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 표시된 주소(기본 `http://localhost:5173`)를 열면 자동으로 지도를 불러오고 기본 걷기로 시작합니다. 입장·모드·마우스 잠금 버튼을 누를 필요가 없습니다.

VR 헤드셋(Meta Quest 등)은 같은 URL을 열고 좌측 **ENTER VR** 버튼을 사용합니다. HTTPS 또는 `localhost`가 필요합니다.

## 조작

| 입력 | 동작 |
|------|------|
| ↑ / ↓ | 현재 시선 기준 전진 / 후진 |
| ← / → | 제자리에서 좌 / 우 시선 회전 |
| ↑ + ← / → | 시선을 돌리면서 그 방향으로 전진 |
| W/S · A/D | 전후진 · 옆걸음 |
| 마우스 (잠금 불필요) | 시점 · 아래 보기 최대 18° |
| 마우스 휠 | 확대/축소 · 확대 시에도 수평선 유지 |
| Shift | 가속 |
| Space | 점프 (걷기) |
| 1 / 2 / 3 | 걷기 / 자전거 / 자동차 |
| 장소 선택 메뉴 | 실제 지도상 주요 장소 주변 산책로로 이동 |

## 데이터

- **출처:** [OpenStreetMap](https://www.openstreetmap.org/copyright) (ODbL)
- **API:** Overpass (`overpass-api.de` 등 미러)
- **범위:** 송도 전역을 포함하는 위도 37.325–37.440, 경도 126.585–126.725 범위 (`src/config.js`의 `SONGDO.bbox`). 사각 범위 안의 주변 지역도 일부 포함됩니다.
- **캐시:** 브라우저 `localStorage`에 7일 보관
- 센트럴파크 기본 지도와 송도 전체 1,704개 기본 타일이 프로젝트에 포함됩니다. 외부 Overpass 연결 없이 구역별 로딩이 가능합니다. 큰 수면·공원·도로는 공유 파일을 사용해 중복을 줄였습니다. 원본 OSM은 `scripts/source/songdo.osm.json`, 출처·목록은 `public/data/songdo-manifest.json`에 있습니다.

건물 높이는 `height` / `building:levels` 태그를 쓰고, 없으면 용도별로 추정합니다. OSM에 높이가 없는 고층은 실제와 다를 수 있습니다.

## 수변 환경 개선판

시작 위치는 실제 OSM 산책로 좌표 **37.3929286, 126.6386891**이며, 센트럴파크 수로 건너편을 바라봅니다. 위치와 바라보는 방향은 `src/config.js`의 `SPAWN`에서 조정합니다.

기존의 원형 수로와 임의 배치 랜드마크 대신 실제 지도 건물 윤곽·산책로·수로를 사용합니다. OSM 멀티폴리곤의 분리된 경계와 안쪽 섬도 연결/보존합니다. 재질은 PBR 기반으로 변경했고, 주 수로는 데스크톱에서 건물/나무의 평면 반사, VR에서는 별도의 반사 카메라를 사용하지 않는 환경 반사 재질을 사용합니다. 지면에는 잔디·아스팔트·포장 표면, 하늘에는 대기 산란과 구름, 수목에는 인스턴싱된 가지·잎을 적용했습니다. 공원 수목은 실제 개별 나무 위치가 아니라 지도 공원 경계 안에서 절차적으로 배치합니다.

마우스를 계속 내려도 기본 하향 각도는 18°에서 멈춥니다. 휠로 확대했을 때는 FOV를 고려해 제한을 더 줄여 화면 상단에 수평선 여유를 남깁니다. 위쪽은 약 65°까지 올려볼 수 있습니다. 이 제한은 마우스 시점에만 적용하며, VR 헤드셋의 실제 머리 회전은 강제로 제한하지 않습니다.

`tests/regression.test.js`는 반복 하향 입력, 모든 줌 범위에서의 수평선 유지, 실제 공원/산책로 위의 시작점, 수로의 섬 보존, 도로 면 방향, 지도 파싱의 재현성을 검사합니다. `dist/`는 사전 빌드 결과입니다. `index.html`을 파일로 직접 여는 대신 Vite 서버나 정적 웹 서버를 사용하세요. 하위 경로 배포를 위해 Vite base는 상대 경로입니다.

### 데이터와 구현 한계

포함 지도는 OpenStreetMap API에서 가져온 센트럴파크 일대 데이터입니다. 출처: https://www.openstreetmap.org/api/0.6/map?bbox=126.628,37.385,126.650,37.400 . © OpenStreetMap contributors, ODbL 1.0: https://opendatacommons.org/licenses/odbl/1-0/ . 원본 데이터와 출처 메타데이터는 `public/data/central-park.json`에 들어 있습니다. 외부 사진, 유료 텍스처, AI 생성 이미지는 사용하지 않습니다.

실제 사진 기반 포토그래메트리/실측 3D 모델이 아니라 지도 윤곽과 높이 태그를 활용한 절차적 재구성입니다. 높이 태그가 없는 건물의 높이와 외벽 디테일은 추정이며 실제 건물과 동일하지 않습니다. 포함 사각 범위의 외곽 지도도 번들로 제공됩니다. 지도가 비어 있는 곳을 가짜 건물·도로로 채우지 않습니다. 실제 VR 기기 성능과 브라우저별 동작은 별도 확인이 필요합니다.


## 송도 전역 탐방·조작 개선

- 건물의 외접 직사각형 대신 원래 다각형 및 중정 구멍으로 충돌을 검사합니다. 이동을 짧은 구간으로 나눠 빠른 이동 시 벽을 관통하는 현상을 줄이고, 새로 로딩된 건물이 플레이어를 가두지 않게 합니다.
- G타워의 경사 상부·삼각 하늘정원, 트라이볼의 세 곡면 보울, 동북아무역타워의 테이퍼, 컨벤시아의 반복 곡면 지붕, 한옥의 기와·처마, 아트포레의 경사 지붕, 아트센터의 분절 매스를 **근사 모델**로 추가했습니다. 실제 건물과 동일한 정밀 모델은 아닙니다.
- 현대아울렛의 지도상 중정 윤곽을 보존하고, OSM에 등록된 주차장을 표시합니다. 주차 구획선은 예시 배치이며 실제 칸 수·주차장 층별 구조를 재현하지 않습니다.
- 인천대학교 건물군, 잭니클라우스 골프장·벙커·수면, 글로벌파크, 해양경찰청, 더샵 센트럴파크, 랜드마크로를 지도 및 주요 목적지에 포함했습니다. 대학·아파트는 주로 지도 윤곽을 압출한 일반 모델입니다.
- 전체 수면 101개, 도로 9,350개, 건물 12,130개, 공원/골프 면 347개, 주차 면 181개, 조형물 등록 위치 45개를 확보했습니다. 이 숫자는 송도 주변까지 포함한 원본 추출 범위의 요소 수이며 실제 도시 전체의 완전한 현황 집계가 아닙니다.
- 수로·호수는 지도의 미터 단위 투영 및 실제 다각형으로 렌더링하며 섬을 유지합니다. 수심·조수·정밀 해안 지형, 실제 모든 고가도로의 높이, 교통 신호·주행 차량은 구현하지 않았습니다.
- **미완료:** 송도국제도서관은 현재 추출 지도에서 확실한 건물 윤곽을 식별하지 못해 임의의 위치·모델을 만들지 않았습니다. 실제 공원 조형물의 모양도 미확보 상태로, 등록 위치에 작은 지도 마커만 표시합니다. 모든 외관·창호·조형물을 실제와 동일하게 만들려면 별도 도면/GLB/BIM 등 사용 가능한 원본이 필요합니다.
- 소프트웨어 GPU는 자동으로 그림자·평면 반사·후처리를 줄입니다. `?quality=low`로 수동 적용할 수 있습니다. 저성능 환경의 목표 프레임률이나 실기기 VR 성능은 보장하지 않습니다.

### 지도 재생성

```bash
node scripts/build-map.mjs
npm test
npm run build
```

`public/data`는 배포에 꼭 포함해야 합니다. 원본 데이터는 OpenStreetMap contributors의 ODbL 1.0 자료입니다. 건축 형태 참고 출처는 지도 목록의 `modelingSources`에 기록되어 있으며 사진 파일을 애셋으로 복제하지 않았습니다.

추가 검증 `tests/songdo-update.test.js`: 방향키 회전과 동시 전진, 잠금 없는 마우스 입력, 비정형 건물·중정 통행, 지도 파일/참조 무결성, 주요 목적지, 랜드마크 형상 및 미완료 표시를 검사합니다. `tests/browser-verification-updated.json`은 외부 Overpass 차단 상태에서의 자동 시작·목적지 로딩·입력 검사 결과입니다. 브라우저 입력 검사는 소프트웨어 GPU의 프레임 지연과 분리하기 위해 일정 시간 간격으로 컨트롤러를 직접 업데이트합니다.
